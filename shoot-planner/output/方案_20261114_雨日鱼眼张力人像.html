主题 + 剧情
主题　雨天的金沙湖大剧院——鱼眼超广角下的张力人像，人是绝对主角，弧墙与水洼只是被拉伸的戏剧垫衬。风格：街头张力·雨日人像（主）/ 情绪疏离·雨日（备）/ 清新日系·雨日（备）。
雨天她来大剧院广场，不是来看戏，是来淋一场。外套敞着、吊带贴身、热裤露腿，撑一把透明伞大步走过弧形白墙前，马丁靴踩过水洼溅起水花。她在立柱边停了一下甩了甩伞上的水，回头冲镜头一个带劲的笑，然后继续往雨里走，越走越远，最后回头一望收尾。
情绪弧线　撑伞大步来（动） → 立柱边甩伞回眸（张力） → 走远回身一望（悬）。先广场水洼前拍远景+全身大步走，再退立柱廊下拍半身甩伞回眸，最后走远拍全身回望+水洼倒影特写。
📌 鱼眼全程人脸放中心，边缘留给建筑弧线和雨；按弧线走，不堆姿势。

设备
⏳ 设备清单见 memory（富士 X-T30II + 铭匠 7.5mm f/1.8 鱼眼，手动对焦）。本次仅列关键补充项：
  • 机身防水套 / 雨衣（鱼眼前组离雨近，必带）
  • 镜头布（多条）+ 密封袋（进室内前入袋缓温防起雾）
  • 备用电池 2 块（冷天+雨天掉电快）
  • 暖宝宝 + 保温杯（给模特，13~18℃雨里穿热裤吊带冷）

胶片模拟：Classic Negative（街头张力首选）/ 备选 Classic Chrome
白平衡：自动偏冷 或 阴天，肤色优先

天气动态调整
✅ 优势
漫射光均匀无硬阴影肤色干净；水洼倒影是额外画面层；雨丝鱼眼边缘拉伸出戏剧感；广场雨天人少好取景
⚠️ 代价
光暗 ISO 高；前组易沾雨起雾；模特穿热裤吊带怕冷；地面湿滑禁跳跃
🔑 雨大→退立柱廊/弧檐下拍半身特写；雨小→广场水洼前全身抓拍；云透光瞬间→逆光拍轮廓发丝。
1. 设备防水第一：鱼眼前组频繁沾雨，每机位都擦；进室内先入密封袋缓温防雾
2. 模特保暖：热裤吊带在 13~18℃ 雨里冷，外套常备拍完即披，暖宝宝贴腰后
3. 地面湿滑：禁跳跃，大步走注意防滑，马丁靴防滑优先
4. 鱼眼畸变：人脸务必画面中心，边缘留给建筑/天空/水洼；纯脸大特写少拍
5. 场地确认：大剧院公共广场/湖边步道通常开放可拍，室内大厅需许可；避开车道与黄线区域
Plan B
🌂 雨变大备选
若中雨持续、广场无法站人 → 转 大剧院立柱廊下 + 弧形檐下 + 周边咖啡馆窗边。
  • 风格延续：仍是雨日鱼眼张力人像，人像为主不变，只换能扛雨的有顶场景
  • 扛天气：立柱廊/弧檐有顶挡雨、地面相对干；咖啡馆窗边可用窗玻璃雨痕做前景
  • 景别调整：远景砍掉（有顶空间局限），重心转中景/近景/特写；窗边加"脸贴窗、雨痕在玻璃"式姿势
  • 剧情：弧线不变（来→停→走远），"走远"改为"廊下走远"或"窗边转身"
  • 设备：廊下光更暗，ISO 1600–3200，f/2.8–4；咖啡馆内可 f/1.8
💡 Plan B 不是另起主题，是同主题换能扛天气的场景。
