# 摆姿库

按风格分组。每个姿势标：**适用光线 / 构图 / 情绪指向 / 难度 / 动作要点**。

用法：方案第 5 环节拿到当天光线后，**只筛适配光线**的姿势进方案，不要整组搬。每组末尾给"小红书自搜关键词"引导用户自行搜参考图（AI 搜小红书不稳定，实际取图走 Unsplash/Pexels/摄影师站）。

适用光线标记含义：
- 硬光 = 晴天直射，适合收敛、侧脸、阴影交互的姿势
- 柔光 = 多云/阴天，适合大动作、飘逸、全方向
- 逆光 = 黄金时段或背光，适合轮廓、剪影、回眸
- 低光 = 蓝调/夜景，适合剪影、情绪特写

## 筛选规则（给 skill 第 5 环节用）

1. 先定当天天气类型（A 表）→ 圈定摆姿基调（外放/收敛/叙事）
2. 再定当天主要时段光线 → 圈定"适用光线"列匹配的姿势
3. 按主题风格选对应分组
4. 三层交集就是该进方案的姿势，每组选 4-6 个，不要全搬
5. 每个进方案的姿势**必须带"适用光线"标注**，没标就是没筛

**反例**：雨天方案里出现"跳跃抓拍"（清新组，适用柔光）= 没筛，要删。

## 输出呈现：按景别（远全中近特）

本库是摆姿后端知识。但**方案输出时不按姿势表呈现，按景别组织参考图**（见 SKILL.md 环节 6）。把筛出的姿势映射到五个景别：

| 景别 | 画面范围 | 典型姿势来源 | 参考图要点 |
|------|----------|--------------|------------|
| 远景 | 人小环境大，交代场景 | 走动中不看镜头、站台纵深感 | 站台/街景全景，人占画面 1/5 以下 |
| 全景 | 全身入画 | 雨中慢走、风衣走动、大步走抓拍 | 全身 + 环境，展现服饰和姿态 |
| 中景 | 膝盖/大腿以上 | 侧身靠墙、撑伞回眸、屋檐避雨望远 | 半身互动，情绪 + 动作 |
| 近景 | 胸像 | 仰望侧脸、背对回头、低头看水洼 | 胸以上，情绪为主 |
| 特写 | 脸/手/物件细节 | 半脸明暗、手撑伞、水洼倒影局部 | 脸、手、伞、水洼等细节 |

输出时每景别 1-3 张外链参考图，**无图的景别保留占位框**（"▌占位：远景·站台全景人小，待补充"），不要用不匹配的图凑数。每景别旁附小红书自搜关键词 + 该景别当天光线要点。
