# 条件→调整映射表

这是 skill"动态"的根。三维：**天气类型 × 时段 × 风格情绪**。每格产出：布光/机位、摆姿基调、道具、备注。

用法：拿到当天天气 + 当前时段 + 主题风格，先查天气类型表定大策略，再按时段细化，最后用风格表做风格化微调。**不是三表乘出来一个格子，是三层叠加**。

---

## A. 天气类型 → 基础策略

按云量和降水分六类。先定大策略。

### A1. 晴天硬光（云量 < 30%）
- **布光/机位**：正午避开（11:00-14:00 光线垂直硬、眼窝鼻下重阴影）。上午用顺光暖色、下午用逆光轮廓光。找阴影边缘拍（树荫/建筑阴影边、半进半出），脸上有柔光背景有硬光。
- **摆姿基调**：收敛、小动作、侧脸/低头避直射、情绪偏静谧或张力。**不要推飘逸跳跃**——硬光下大动作汗水+眯眼+乱发全毁。
- **道具**：反光板（必带，补脸用，银面或金面看想要冷还是暖）、遮阳帽/伞（既道具又挡光）。
- **备注**：一天里效率最低的天气，时段卡得严。黄金时段必须提前踩点，错过就没了。

### A2. 多云柔光（云量 40-80%，无降水）
- **布光/机位**：全天可拍，效率最高。大光圈全开，全方向都能拍。云层就是天然柔光箱，肤色最均匀。逆光时云层会透出柔和轮廓光。
- **摆姿基调**：飘逸、走动、跳跃、回眸、大动作全开。情绪可外放。这是摆姿库发挥最-full 的天气。
- **道具**：落叶/花瓣/纱/长裙/气球——所有"需要风和动态"的道具都这天用。
- **备注**：多云是户外人像最优天气。若云量偏厚（接近阴天）注意画面偏灰，靠服装色系和后期拉对比。

### A3. 阴天重云（云量 > 80%，无降水）
- **布光/机位**：光均匀但偏暗偏冷。提高 ISO、开大光圈、找亮色背景（白墙/浅色建筑）提亮画面。逆光没轮廓光，别指望。朝天空拍要压曝光否则脸黑。
- **摆姿基调**：情绪特写、低头、侧脸、安静叙事。大动作在这种光下显得没精神，**改成走动中的抓拍**比定格摆姿好。
- **道具**：透明伞（既挡微光又当道具）、亮色外套（破灰）、纸伞。
- **备注**：色温偏冷，后期要暖调补偿，或干脆走冷调情绪路线别硬救。

### A4. 雨天（有降水）
- **布光/机位**：能见度低、光暗。找有顶场地（回廊/屋檐/天桥下/车棚）或车拍。地面水洼可拍倒影。镜头起雾要备镜头布+密封袋（从冷到暖环境缓温）。
- **摆姿基调**：避雨姿态、低头看水洼、撑伞回眸、车窗内特写。情绪偏叙事、冷、孤。
- **道具**：透明伞（首选，能看见脸）、雨衣、纸巾、防水袋（保护设备）。
- **备注**：设备防水是第一优先级。机身防溅溅等级不够要套防水套。模特怕冷要带外套。
- **这是最该触发 Plan B 的天气**，但有顶场地往往能出最有故事感的片，别急着放弃。

### A5. 起风/大风
- **布光/机位**：收三脚架（风大不稳定），降快门抓拍动态。空旷高处（天台/桥）危险避开。逆光下头发/裙摆飘起来反而好看。
- **摆姿基调**：动态抓拍为主——回眸让风吹发、裙摆被吹起、低头避风。**别推定格站立**，风下定格摆姿头发糊脸全废。
- **道具**：丝巾/长裙/纱（被吹起好看）、帽子要系绳（防吹丢）。
- **备注**：注意安全，沙尘天保护设备（换镜头要快或干脆不换）。风+逆光是出片利器组合。

### A6. 雾/霾
- **布光/机位**：雾是天然空气透视，远近层次分明，适合中长焦拍空间感。逆光雾会发光。霾偏脏，能见度差且不健康，**重霾天建议直接改 Plan B 或改期**。
- **摆姿基调**：远景剪影、侧脸轮廓、安静。雾天细节被吃掉，靠轮廓和氛围。
- **道具**：透明伞、亮色围巾（破灰白单调）。
- **备注**：雾天 AQI 通常不好，关注模特和拍摄者呼吸道。轻雾出片，重霾不出。

## B. 时段细化

在天气大策略基础上，按时段调整。

| 时段 | 光线特征 | 策略调整 |
|------|----------|----------|
| 日出-晨金（日出后 1h） | 低角度暖光、柔、短 | 最优时段之一，顺光暖肤色，逆光轮廓。提前到场，时段短 |
| 上午（黄金后-11:00） | 光渐硬、角度渐高 | 晴天开始要找阴影；多云全天无所谓 |
| 正午（11:00-14:00） | 垂直硬光 | 晴天**避开或转棚/室内/Plan B**；多云/阴天无所谓 |
| 午后金（日落前 2-1h） | 低角度暖光、变硬 | 逆光轮廓光黄金时段，摆姿可外放但要控汗 |
| 蓝调（日落后 20-40min） | 冷蓝、低反差 | 剪影、城市灯光补光、情绪路线。需要高 ISO 或脚架 |
| 夜景 | 人工光为主 | 城市灯光背景、慢门、补光设备上场 |

**黄金时段是最贵的资源**：晴天黄金时段短且不可错过，多云黄金时段更柔但轮廓弱。方案时间安排表要把黄金时段标成"必拍窗口"，前后留给踩点和转场。

## C. 风格情绪适配

同一天气，不同风格反应不同。拿到主题风格后做这层微调。

### 情绪/疏离/冷峻
- 晴天硬光 → 反而合适，硬阴影强化情绪；找几何阴影、半脸明暗
- 多云柔光 → 也合适，靠构图和模特表情出情绪，不靠光
- 雨天 → 最契合，叙事感最强
- **道具倾向**：冷色、几何、Minimal

### 清新/温柔/日系
- 晴天硬光 → 不太合适，太硬；用阴影/逆光救
- 多云柔光 → 最优，肤色干净画面通透
- 摆姿外放，道具倾向亮色、轻盈
- **正午硬光是清新风格的天敌**，要么躲要么改期

### 复古/胶片感
- 晴天黄金时段 → 最优，暖光+暖色系=胶片味
- 阴雨 → 也可，靠后期调色
- 道具倾向旧物、暖色、纸质感

### 街头/张力
- 几乎全天候，靠场景和动态
- 硬光反而强化街头感
- 雨夜街头张力最强

### 古风
- 晴天黄金或柔光 → 最优
- 大风 → 不合适（发型和衣袂难控，除非要飘逸感）
- 道具倾向纸伞、团扇、古籍

---

## D. 组合决策（if-then 速查）

把三层叠成可执行的 if-then。举例让格式落地：

- **if 晴天硬光 + 正午 + 清新风格** → 转阴影/室内/Plan B，别硬刚正午
- **if 多云柔光 + 午后金 + 情绪疏离** → 大光圈逆光轮廓，摆姿安静侧脸
- **if 雨天 + 蓝调 + 街头张力** → 有顶回廊 + 城市灯光背景 + 透明伞 + 抓拍
- **if 起风 + 午后金 + 复古** → 逆光下裙摆飘起抓拍，长焦压缩，暖色调
- **if 阴天重云 + 全天 + 清新** → 找亮色背景提亮，大光圈，摆姿走动抓拍代替定格

方案第 5 环节就是查这张表 + 写成自然语言策略。**输出要落到具体机位和具体姿势，不要停在"建议找阴影"这种抽象层**。
