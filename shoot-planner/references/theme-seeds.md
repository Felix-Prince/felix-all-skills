# 主题种子库

把用户模糊想法扩展成完整主题概念用。**不是查表直接抄，是参考方向后结合当天天气和地点再创作**。

格式：`想法关键词 → 关联场景 / 情绪基调 / 色系 / 道具 / 风格定位 / 小红书自搜关键词`

用法：第 2 环节拿到用户想法后，先在这张表找最接近的种子，取它的方向元素，**再结合天气和地点微调成当天专属主题**。完成后输出主题四件（场景叙事/情绪基调/视觉关键词/推荐风格）给用户确认。

## 想法种子表

### 地铁 JK 少女
- 关联场景：晚高峰退潮的站台、空车厢、地铁出口光、扶梯、换乘通道
- 情绪基调：疏离 / 日系街头 / 青春
- 色系：暗调车站 + JK 深蓝/格纹 + 肤色暖
- 道具：单肩包、耳机、透明伞、饮料罐
- 风格定位：日系街头情绪（主）/ 清新日系（备选）
- 小红书自搜：`JK 地铁 拍照姿势` / `地铁站 拍照`
- **剧情示范**：她一个人坐在空站台的长椅上，耳机里放着歌，列车开走又停下她都没动。雨下大了，她撑开透明伞走到出站口的光里站住，像是在等什么人，又像只是不想走进雨里。开场是疏离的静，推进是雨中的动，收尾是出站口光下的一停——情绪弧线从冷到动到悬。

## 扩展原则（没命中表里时的兜底）

用户给的想法没命中上表时，按以下原则自行扩展：

1. **拆场景**：想法里有没有明确场景词（地铁/海边/咖啡馆）？有就围绕它；没有就从情绪反推场景（疏离→车站/老巷，清新→公园/窗边）。
2. **定情绪**：从想法词的色彩感定情绪。JK=青春疏离，秋日=温柔怀旧，海边=辽远冷。
3. **锁色系**：情绪冷→冷色系，情绪暖→暖色系。别让冷情绪配高饱和暖色。
4. **选道具**：从场景+情绪交集选。地铁站+疏离=耳机/透明伞/饮料罐；海边+辽远=长裙/草帽。
5. **风格定位**：优先情绪疏离 / 清新日系 / 复古胶片 / 街头张力 / 古风 五选一，不够再混合。
6. **小红书关键词**：场景 + 对象 + 动作类型三词组合，具体不宽。

## 风格定位五类速查

供第 2 环节"推荐风格"用。每个风格一句话定调 + 典型光线：

- **情绪疏离**：孤独、冷、叙事感。典型光线：硬光几何阴影 / 阴天均匀 / 雨夜
- **清新日系**：明亮、通透、外放。典型光线：多云柔光 / 黄金时段逆光
- **复古胶片**：暖、怀旧、质感。典型光线：黄金时段暖光
- **街头张力**：动态、都市、广角。典型光线：全天候，硬光强化
- **古风**：古典、雅、飘逸。典型光线：黄金或柔光，忌大风

**推荐风格时，结合当天天气往典型光线匹配的风格上靠**。雨天推"情绪疏离"比推"清新日系"合理——这本身就是动态调整的一部分，从主题环节就开始了。
